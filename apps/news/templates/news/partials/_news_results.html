The search box, the period control and the sort chips all stay outside: htmx replaces this element's contents, and an input inside would lose its caret on every keystroke. The count above the table is updated separately, by an out-of-band swap — see `_news_search_response.html`. Pagination stays ordinary links. A reader asking for page two has stopped typing, and a real navigation keeps the back button meaning what it says. {% endcomment %} {% if archive.has_rows %} {% comment %} Deliberately **not** `min-w-max`. Every other table on this dashboard sets it and scrolls inside its wrapper, which is right for a row of figures that has a natural width — and wrong here. An article title has no natural width, so `min-w-max` sized the table to the longest headline on the page and put the archive behind a horizontal scrollbar at every width below about 1900. On a phone that means dragging sideways to read a headline. The title column wraps instead. The date and the figure are the columns that must not break, so those two carry `whitespace-nowrap` and the title takes whatever is left — one line for an ordinary headline at any width, two for a long one on a phone. {% endcomment %}
{% comment %} `break-all` below `sm` is what lets this table fit a 320-pixel phone, and the choice of property is the whole point: a column cannot shrink below its longest unbreakable word, and `Lehevaatamised` is fourteen characters of one, with the longest word of a headline beside it. Together they came to 38 pixels more than the viewport. `overflow-wrap: break-word` — Tailwind's `break-words` — does not help, and that is not a subtlety worth rediscovering: it permits a break when a line would overflow but is defined not to reduce the intrinsic minimum content size, so the table's minimum stayed exactly what it was. `word-break: break-all` does reduce it. Applied only below `sm`. Breaking Estonian mid-word is worth it at 320 pixels and is not worth it anywhere else. {% endcomment %} {% for row in archive.rows %} {% comment %} The date must not break; `Kuupäev teadmata` may.
