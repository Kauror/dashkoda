{# ---------------- Õigusloome ---------------- #} {% if page.has_legal_lists %} {% comment %} The two lists the board reads together: what is in work and what has most recently gone out. `Töös` is ordered by the opinion deadline rather than by arrival — what a reader wants off this list is what has to leave next — and something overdue is in work most of all, so it leads rather than being filtered away. **A topic is a link only when the read path resolved an address for it**, and which address depends on the record's own status: a sent opinion points at its resource page, which carries the PDF; an open unsent one points at the `Hetkel käsil` consultation, which is the "küsime arvamust" invitation. The two are mutually exclusive by construction, so no row can offer both. A row whose match is stale or missing is plain text on purpose — `topic_links` refuses an address computed against a different snapshot, because a lawyer sent to last week's consultation is worse off than one sent nowhere. `legal_topic.html` is the same component the Õigusloome page uses, so the rule about when a topic is clickable cannot hold there and not here. {% endcomment %}
