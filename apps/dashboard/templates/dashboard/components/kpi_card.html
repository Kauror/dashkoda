{% comment %} KPI card. Context (every field is optional except label; anything missing degrades to an explicit "no verified data" state rather than to a guess): label – indicator name value – the measured value, already formatted unit – unit shown after the value change – signed change against the comparison period change_direction – up | down | flat, used for the textual direction marker comparison_period – what the change is measured against secondary – one supporting line, e.g. the amounts behind a percentage. Rendered only beside a hero `value`: a details-only cell has no figure for it to support, so passing it there computes a string that never reaches the page. Put the extra line in `details` instead. details – supporting counts, each `.label` beside its `.value`; used where a module has several figures of equal weight and one of them promoted to a hero number would misstate the rest. A row with a `.url` links its label to the section that lists the records behind the count; one without stays plain text, because a count whose module has no section listing exactly those rows must not link somewhere approximate. The link wears `dk-link-quiet`, not `dk-link`: these are labels under a figure, and three of the ordinary blue rule in one small cell competes with the counts the cell exists to show meter_pct – 0–100; draws a proportion bar beneath the value status – neutral | brand | success | warning | danger | info status_label – text for the status badge as_of – date the value describes empty_message – shown instead of a value when none is available flush – drop the card's own border, for use inside a divided strip Direction is expressed in text as well as colour, so colour is never the only signal. The presence test is `is not None`, not truthiness: an explicitly reported zero is a real measurement and must stay distinguishable from a blank. The meter is an inline SVG whose bar length is a geometry **attribute**, never a width inside a `style`. The Content Security Policy is `style-src 'self'` and `tests/dashboard/test_overview.py` asserts no `style="` reaches the page, so a proportion may only be drawn as geometry. Colour comes from Tailwind `fill-*`. {% endcomment %}
