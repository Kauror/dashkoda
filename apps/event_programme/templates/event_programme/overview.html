The Chamber's own event programme, from the canonical Excel export: the whole available history in one current snapshot. Every figure and every row on this page comes from that one snapshot; rows from several snapshots are never combined to reconstruct a past. One route, six focus views, chosen by `?fookus=`. The header, the year control and the provenance block are constant; the analytical surface between them changes. An unknown focus falls back to `Ülevaade` rather than producing an error page. The measurement object is one **canonical programme event** — one service code, one row of `DASH_EVENTS`. It is not a session and not a calendar day, and the page says so where a reader might otherwise assume otherwise. What this page never shows, because no source establishes it: attendance, participants, capacity, fill rate, no-show rate or satisfaction. Page views are page views, not people; Commerce registration units are transactions, not attendees. {% endcomment %} {% block title %}Sündmused – DashKoda{% endblock %} {% block extra_head %} {% comment %} The chart bundle loads only for the focus views that draw something.
