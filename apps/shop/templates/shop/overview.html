Three disclosures come before any figure, because each one changes how every number below should be read: * **the as-of line.** The dataset is a manual export that stops on a stated day. It is never described as live, synchronised or current; * **the Commerce span**, so "Kõik" has a stated meaning; * **the comparison interval**, whenever the web figures cover less than the Commerce ones — which is the ordinary case, GA4 starting two and a half years after the order history. Two page-view columns are shown for documents and they are never added together. A visitor commonly sees both the informational page and the product page, so their sum is not reach. The rate uses the product page alone, because that is the page carrying the buy action. A dash is a dash. `—` means "not measured"; a zero means "measured, and it was zero".
