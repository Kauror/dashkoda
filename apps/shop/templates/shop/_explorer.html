{% comment %} The whole-population product explorer. Search, sorting and paging all run on the server across every product in scope, never across the rows currently on screen — a product ranked #347 is exactly the kind somebody looks up, and a client-side filter would answer only for the twenty-five already rendered. Five columns, and the category rides inside the product cell as muted secondary text rather than taking a column of its own. On a phone that is the difference between a readable table and seven numeric columns nobody can scan; the table scrolls inside its own wrapper so the page never scrolls sideways. Sorting lives on the headers, so the control sits on the thing it orders. `aria-sort` carries the state for a screen reader; the arrow is the visual echo of it rather than the only signal. {% endcomment %}
