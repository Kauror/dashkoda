{% comment %} The five analytical views of E-pood, at one route. `aria-current="page"` rather than `"true"`: these are navigation links to the same document in a different state, which is what `page` means, and a screen reader announces it as the current page rather than merely as a pressed control. Every link carries the period, the product type, the categories and the search already chosen — `build_query` composes them — so moving between views never silently resets what the reader set up. The links are ordinary anchors, so the back button, a bookmark and a shared URL all behave. The row scrolls horizontally on a narrow screen rather than wrapping into two ragged lines, and the scroll is inside this element so the page itself never scrolls sideways: `min-w-max` on the list is what makes the tabs keep their width, and `overflow-x-auto` on this element is what contains them. Deliberately no negative margin. Pulling the first tab flush with the heading would widen this element past its parent, and on a 320px screen that is how a page starts scrolling sideways — the recurring layout bug in this repository. {% endcomment %}
