This template chooses layout and nothing else — no filter here decides how a share, a percentage-point movement or a signed count is written, because that decision lives in `apps.visibility.website_page` beside the one the chart tooltips use. A row may carry `bar_pct`, and then its **leading figure** is drawn with a bar behind it. A ranking is read as shape before it is read as numbers, and a column of right-aligned figures makes the reader do the ordering the shape can do for them. The bar is SVG **geometry**, never an inline width: the Content Security Policy is `style-src 'self'`, so a proportion may only be drawn as an attribute. Colour comes from Tailwind `fill-*`. The table owns its own horizontal scroll container, so a wide table never makes the page itself scroll sideways on a phone. Nothing inside it is `sr-only`: an absolutely-positioned note settles at its untruncated text width and widens the whole document while the table scrolls correctly inside its wrapper and looks innocent — this codebase's recurring layout bug.
