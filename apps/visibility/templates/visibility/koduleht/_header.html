{% comment %} The page header: what this is, how current the source is, which view, which window. The focus navigation and the period control are separate on purpose. One chooses the question, the other chooses the window it is asked over, and every link carries both — so changing the view never silently changes the period, and changing the period never drops the reader back to the overview. A period the history cannot fill is shown **disabled rather than hidden**. A reader who looks for `5 aastat` and finds no such control learns nothing; one who finds it inert learns the Chamber has not been measuring that long. The custom range is a real GET form with two date inputs, so it works with no JavaScript. Its hidden fields carry the server-resolved view and section rather than the incoming query string, which is what keeps an unvalidated parameter from being reflected back into an address. {% endcomment %}
