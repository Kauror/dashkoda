{% comment %} One proportion: a stacked bar, and the bands beneath it as a legend. Context: title – section heading heading_id – required, referenced by the section's aria-labelledby description – optional, a line beneath the heading bar – tuple of MixSegment, already positioned table – the matching TableView, one row per band, in the same order The bar is SVG **geometry** — every offset and width is an attribute, never an inline style, because the Content Security Policy is `style-src 'self'`. The bands are positioned in Python for the same reason a share is formatted there: a cumulative offset is arithmetic, and arithmetic in a template is a rule nobody can test. **A bar that does not reach the end is the honest drawing.** `build_mix_bar` gives an unmeasured band no segment rather than a zero-width one, and nothing stretches the remainder to fill — a partly classified population looks partly classified. The colour is named by slot, spelled out branch by branch. A class assembled at render time — `fill-series-{{ slot }}` — simply would not exist, because Tailwind generates utilities by scanning these files for literals. The swatch and its segment share the row's `slot`, so the legend and the drawing cannot drift apart. The bar itself is `aria-hidden`: it is the same figures the legend states in words, and a screen reader reading a row of coloured rectangles learns nothing the rows below do not say better. {% endcomment %}
