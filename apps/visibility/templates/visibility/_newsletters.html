{% comment %} A plain GET form. Without the bundle it submits, the page reloads, and the same rows come back rendered server-side; with it, the input's `hx-*` attributes filter the table below as somebody types and the form is never submitted at all. Neither path is the fallback of the other. The active newsletter travels as a hidden field, so searching inside e-Teataja stays inside e-Teataja — submitting a search must not quietly widen the question. `min-w-0` on the wrapper and the input is what stops a long term pushing the document sideways on a phone, and the label is real rather than a placeholder, because a placeholder disappears the moment somebody types. It searches the subject stored in PostgreSQL and never contacts Smaily, exactly as the archive page's box does — same parameter name, same question, so the "vaata kõiki" link below can simply carry it across. Four attributes carry the live behaviour, and each is load-bearing: - `input changed delay:250ms` debounces. `changed` is what stops an arrow key or a keystroke that leaves the value alone from spending a query; - `search` is the second trigger, for the native clear button `input type=search` draws — without it, clearing the box with the mouse leaves the last results on screen; - `hx-include="closest form"` sends the hidden newsletter alongside the term, so a live search is narrowed exactly as a submitted one; - `hx-sync="this:replace"` aborts an in-flight request when the next keystroke arrives. Without it two answers race and the slower one can land last, leaving results for a prefix of what the box says. {% endcomment %}
