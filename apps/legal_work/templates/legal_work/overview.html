{% extends "dashboard/shell.html" %} {% load static %} {% comment %} Õigusloome intelligence dashboard. One page and one URL. `fookus` chooses which analytical surface is drawn, so every view is bookmarkable, shareable and reload-safe, and the back button moves between them like it moves between any two pages. There is no SPA and no client-side routing: the server renders the focus it was asked for. Every value comes from one imported snapshot, and the page reads PostgreSQL and nothing else. It never contacts Microsoft, never parses a workbook and never reads Koda.ee while serving a request. What the page still refuses to show is as deliberate as what it draws: no responsible lawyer, no member names or companies, no member response rate, no forecast and no composite score. Those are not hidden columns — most do not exist in the model, and the ones that do are counts rather than identities. `section-figures`, `section-open` and `section-sent` are linked into from the dashboard overview. They stay on the default focus and keep their ids; `apps/legal_work/sections.py` names them and a test holds the page to them. {% endcomment %} {% block title %}Õigusloome – DashKoda{% endblock %} {% block extra_head %} {% comment %} The chart bundle is over a megabyte, so it loads only on a focus that actually draws something.
